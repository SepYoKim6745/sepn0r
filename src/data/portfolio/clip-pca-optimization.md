## 연구 배경

CLIP(Contrastive Language-Image Pre-training)은 텍스트와 이미지를 동일한 임베딩 공간에 매핑하여 멀티모달 검색을 가능하게 하는 대표적인 비전-언어 모델이다. 그러나 CLIP이 생성하는 고차원 임베딩 벡터는 대규모 데이터셋에서 저장 비용과 검색 지연 시간을 증가시키는 요인이 된다. 특히 실시간 검색 시스템이나 엣지 디바이스 환경에서는 임베딩 차원의 경량화가 실용적 배포를 위한 핵심 과제로 부상하고 있다.

본 연구는 CLIP 기반 검색 시스템에서 사후 임베딩 처리 단계에 PCA(Principal Component Analysis)를 적용하여, 모델 재학습 없이도 임베딩 차원을 효과적으로 축소할 수 있는 방법론을 제안한다.

## 방법론

본 연구에서 제안하는 접근법은 사후 임베딩 PCA 경량화(post-embedding PCA compression)로, 사전 학습된 CLIP 모델의 출력 임베딩에 PCA 변환을 적용하는 방식이다. 이 방법의 핵심 장점은 원본 CLIP 모델을 수정하거나 재학습할 필요가 없다는 점이다.

구체적으로는 다음과 같은 파이프라인을 따른다.

1. 사전 학습된 CLIP 모델로 이미지 및 텍스트 임베딩을 추출한다.
2. 추출된 임베딩 집합에 대해 PCA를 수행하여 주성분을 산출한다.
3. 원본 차원에서 축소된 차원으로 임베딩을 변환한다.
4. 축소된 임베딩 공간에서 코사인 유사도 기반 검색을 수행한다.

PCA 적용 시 분산 보존율(explained variance ratio)을 기준으로 최적 차원 수를 결정하며, 검색 정확도와 차원 축소율 간의 균형점을 실험적으로 탐색하였다.

## 주요 결과

실험 결과, PCA를 통한 차원 축소가 원본 CLIP 임베딩 대비 상당한 수준의 차원 절감을 달성하면서도 검색 성능의 저하를 최소화할 수 있음을 확인하였다. 특정 축소 비율까지는 검색 정확도가 거의 유지되며, 임계점을 넘어서면 성능이 급격히 하락하는 경향이 관찰되었다. 이를 통해 실용적으로 적용 가능한 최적 차원 축소 범위를 도출하였다.

또한 PCA 기반 경량화는 모델 재학습이 불필요하므로, 기존 CLIP 기반 시스템에 후처리 모듈로 손쉽게 통합할 수 있다는 실용적 이점을 가진다. 저장 공간 절약과 검색 속도 향상 측면에서도 유의미한 개선이 확인되었다.

## 기술 스택

- **모델**: OpenAI CLIP (ViT 기반 인코더)
- **차원 축소**: PCA (scikit-learn)
- **프레임워크**: Python, PyTorch
- **평가**: 코사인 유사도 기반 검색 정확도 (Recall@K)
