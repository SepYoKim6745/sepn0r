## 프로젝트 소개

sepn0r는 강의 실습 자료와 포트폴리오를 한곳에서 관리하기 위해 만든 개인 사이트이다. 수업에서 사용하는 실습 자료를 학생들이 웹에서 바로 열람하고, 필요한 파일을 내려받을 수 있도록 설계했다. 동시에 개인 프로젝트를 정리하는 포트폴리오 공간도 함께 운영한다.

## 기술 스택

- **Astro v5**: 정적 사이트 생성기로, 콘텐츠 중심 사이트에 적합한 빠른 빌드와 제로 자바스크립트 기본 출력을 활용한다.
- **Tailwind CSS v4**: 유틸리티 퍼스트 CSS 프레임워크로 일관된 디자인 시스템을 유지한다.
- **Content Collections**: Astro의 콘텐츠 컬렉션으로 Markdown 파일을 구조화하고, Zod 스키마로 frontmatter를 빌드 타임에 검증한다.
- **TypeScript**: 타입 안전성을 확보하여 런타임 오류를 사전에 방지한다.
- **GitHub Pages**: 정적 배포 환경으로, `/sepn0r` base path를 통해 서빙한다.

## 주요 기능

- **실습 자료 시스템**: 16개 이상의 실습 자료를 카테고리별로 분류하여 제공한다. 각 자료에는 단계별 설명, 코드 예시, 연습 문제가 포함되며, PDF 및 실습 파일 다운로드를 지원한다.
- **포트폴리오**: 개인 프로젝트를 정리하여 기술 스택, 라이브 데모 링크, 소스 저장소와 함께 소개한다.
- **프롬프트 평가기 (Prompt Scorer)**: AI 프롬프트의 품질을 평가하는 도구를 내장하여 실습에 활용한다.
- **반응형 디자인**: 모바일부터 데스크톱까지 모든 화면 크기에서 동작하는 레이아웃을 제공한다.

## 설계 결정

- **Neutral 전용 팔레트**: Tailwind의 neutral 계열 색상만 사용하여 시각적 일관성을 유지하고, 콘텐츠 자체에 집중할 수 있는 환경을 만들었다.
- **Base Path 처리**: GitHub Pages의 서브 디렉토리 배포 특성에 맞춰 모든 내부 링크와 에셋 경로에 `${baseURL}` 접두사를 적용하는 규칙을 수립했다.
- **콘텐츠 주도 아키텍처**: Markdown 파일과 Zod 스키마를 중심으로 콘텐츠를 관리한다. 새로운 실습 자료나 포트폴리오 항목을 추가할 때 Markdown 파일 하나만 작성하면 사이트에 자동 반영된다.
- **빌드 타임 검증**: frontmatter 필드를 Zod로 검증하여 잘못된 날짜 형식, 누락된 필수 필드, 유효하지 않은 URL 등을 빌드 단계에서 차단한다.
