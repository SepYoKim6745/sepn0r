## 프로젝트 소개

개발자이자 강사로서 활동하면서 필요한 개인 홈페이지를 만들었습니다.

### 주요 기능

- **실습 자료 관리**: 마크다운으로 실습 자료를 작성하고 자동으로 사이트에 반영
- **포트폴리오**: 프로젝트를 정리하고 공유
- **반응형 디자인**: 모바일부터 데스크탑까지 최적화

### 기술 스택

- Astro v6 (정적 사이트 생성)
- Tailwind CSS v4 (스타일링)
- TypeScript (타입 안전성)
- GitHub Pages (배포)
