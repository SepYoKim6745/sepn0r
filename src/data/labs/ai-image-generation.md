## 오늘의 학습 목표

- 🟢 **목표 1:** 텍스트 프롬프트만으로 원하는 이미지를 생성할 수 있다
- 🟢 **목표 2:** 스타일 키워드를 활용하여 이미지의 분위기와 화풍을 제어할 수 있다
- 🟢 **목표 3:** 생성된 이미지에 수정 요청을 전달하여 원하는 방향으로 개선할 수 있다
- 🟢 **목표 4:** 실무(SNS 썸네일, 발표 자료)에 활용 가능한 이미지를 직접 제작할 수 있다

## 실습 1) 첫 이미지 생성하기 `난이도 1`

> **📌 미션:** AI에게 간단한 프롬프트를 입력하여 첫 번째 이미지를 생성해보세요.

AI 이미지 생성의 기본 원리는 간단합니다. **텍스트로 원하는 장면을 설명**하면, AI가 그에 맞는 이미지를 만들어줍니다.

처음에는 짧고 단순한 프롬프트부터 시작해봅시다.

**시도해볼 프롬프트:**

```
바다 위에 떠 있는 작은 배
```

이 프롬프트로 이미지를 생성한 뒤, 결과를 저장하세요.

<details><summary>✅ 정답 예시</summary>

```
잔잔한 바다 위에 떠 있는 작은 나무 배, 맑은 하늘, 햇빛이 수면에 반사되는 모습
```

짧은 프롬프트도 이미지를 생성할 수 있지만, **구체적으로 쓸수록 원하는 결과에 가까워집니다.** 첫 번째 결과와 비교해보세요.

</details>

## 실습 2) 구체적 묘사의 힘 `난이도 1`

> **📌 미션:** 하나의 장면을 **주제 + 배경 + 분위기 + 구도** 4가지 요소를 모두 포함하여 프롬프트를 작성하세요.

AI 이미지 프롬프트의 핵심은 **4가지 묘사 요소**입니다:

| 요소 | 설명 | 예시 |
|------|------|------|
| **주제** | 무엇을 그릴 것인가 | 고양이, 카페, 로봇 |
| **배경** | 어디에 있는가 | 숲속, 도시 야경, 우주 |
| **분위기** | 어떤 느낌인가 | 따뜻한, 신비로운, 활기찬 |
| **구도** | 어떤 시점/앵글인가 | 클로즈업, 조감도, 정면 |

**연습할 주제:** "카페에서 책을 읽는 사람"

아래 표를 채워서 프롬프트를 완성하세요:

| 요소 | 내 프롬프트 |
|------|-------------|
| 주제 | |
| 배경 | |
| 분위기 | |
| 구도 | |

<details><summary>✅ 정답 예시</summary>

```
아늑한 카페 창가에서 책을 읽고 있는 여성, 따뜻한 오후 햇살이 들어오는 실내, 
나무 테이블 위에 커피 한 잔, 평화롭고 조용한 분위기, 측면 중간 거리 구도
```

| 요소 | 내용 |
|------|------|
| 주제 | 책을 읽고 있는 여성, 커피 한 잔 |
| 배경 | 아늑한 카페 창가, 나무 테이블 |
| 분위기 | 따뜻한 오후 햇살, 평화롭고 조용한 |
| 구도 | 측면 중간 거리 |

</details>

## 실습 3) 스타일 키워드 활용 `난이도 2`

> **📌 미션:** 같은 주제를 **3가지 다른 스타일**로 생성하고, 결과를 비교하세요.

프롬프트 뒤에 **스타일 키워드**를 붙이면 이미지의 화풍이 완전히 달라집니다.

자주 쓰이는 스타일 키워드:

| 키워드 | 효과 |
|--------|------|
| `watercolor painting` | 수채화 느낌 |
| `3D render` | 3D 렌더링 |
| `pixel art` | 픽셀 도트 그래픽 |
| `oil painting` | 유화 느낌 |
| `flat illustration` | 플랫 일러스트 |
| `photograph, realistic` | 사실적 사진 |
| `anime style` | 애니메이션 스타일 |
| `minimalist line art` | 미니멀 라인 드로잉 |

**공통 주제:** "산 위의 작은 오두막"

이 주제에 서로 다른 스타일 키워드를 붙여 3장을 생성해보세요.

<details><summary>✅ 정답 예시</summary>

**스타일 1 — 수채화:**
```
산꼭대기의 작은 나무 오두막, 주변에 소나무 숲, 안개가 낀 아침, watercolor painting
```

**스타일 2 — 3D 렌더링:**
```
산꼭대기의 작은 나무 오두막, 주변에 소나무 숲, 안개가 낀 아침, 3D render, soft lighting
```

**스타일 3 — 픽셀 아트:**
```
산꼭대기의 작은 나무 오두막, 주변에 소나무 숲, 안개가 낀 아침, pixel art, 16-bit style
```

같은 장면이라도 스타일 키워드에 따라 완전히 다른 결과물이 나옵니다. **용도에 맞는 스타일을 선택하는 것**이 핵심입니다.

</details>

## 실습 4) 이미지 수정 요청 `난이도 2`

> **📌 미션:** 실습 3에서 생성한 이미지 중 하나를 골라, **수정 요청을 3회** 보내서 점진적으로 개선하세요.

AI 이미지 생성은 한 번에 완벽한 결과를 내기 어렵습니다. **대화를 이어가며 수정 요청**을 보내는 것이 실전 활용법입니다.

수정 요청 시 효과적인 표현 패턴:

| 패턴 | 예시 |
|------|------|
| **추가** | "왼쪽에 강아지를 추가해줘" |
| **제거** | "배경의 구름을 제거해줘" |
| **변경** | "하늘 색을 노을빛으로 바꿔줘" |
| **강조** | "오두막을 더 크고 눈에 띄게 해줘" |
| **분위기 조절** | "전체적으로 더 따뜻한 색감으로 바꿔줘" |

<details><summary>✅ 정답 예시</summary>

**1차 수정:**
```
이 이미지에서 오두막 앞에 작은 연못을 추가해줘
```

**2차 수정:**
```
하늘을 노을이 지는 모습으로 바꿔줘. 주황색과 보라색이 섞인 하늘
```

**3차 수정:**
```
전체적으로 색감을 더 따뜻하게 조정하고, 오두막 창문에서 불빛이 새어나오게 해줘
```

수정을 거듭할수록 원하는 이미지에 가까워집니다. **한 번에 하나씩** 요청하는 것이 결과를 제어하기 쉽습니다.

</details>

## 실습 5) 실무 활용: SNS 썸네일 `난이도 2`

> **📌 미션:** 가상의 SNS 게시물을 위한 **썸네일 이미지**를 생성하세요.

실무에서 AI 이미지를 가장 많이 활용하는 분야 중 하나가 **SNS 콘텐츠 제작**입니다. 썸네일용 이미지를 만들 때는 다음을 고려하세요:

- **단순하고 눈에 띄는 구도** (복잡한 장면은 작은 썸네일에서 알아보기 어려움)
- **밝고 선명한 색상** (피드에서 시선을 끌어야 함)
- **텍스트가 들어갈 여백** (제목이나 문구를 넣을 공간 확보)
- **비율 지정** (정사각형 1:1, 가로형 16:9 등)

**시나리오:** 건강 레시피 블로그의 "여름 과일 스무디 레시피" 게시물 썸네일

<details><summary>✅ 정답 예시</summary>

```
밝고 화사한 여름 분위기의 과일 스무디 사진, 딸기와 망고 스무디가 유리잔에 담겨 있고
주변에 신선한 과일이 배치되어 있다, 흰색 대리석 테이블 배경, 
위쪽에 텍스트를 넣을 수 있는 여백 확보, 음식 사진 스타일, 밝은 자연광 조명,
정사각형 비율, 위에서 살짝 비스듬히 내려다보는 구도
```

**포인트:** 텍스트 오버레이를 위한 **여백 확보**를 프롬프트에 명시하면, 나중에 편집 도구에서 제목을 넣기 수월합니다.

</details>

## 실습 6) 실무 활용: 프레젠테이션 삽화 `난이도 3`

> **📌 미션:** 가상의 발표 자료에 들어갈 **개념 설명 삽화**를 생성하세요.

발표 자료에 AI 이미지를 활용하면 **무료 스톡 이미지에 의존하지 않고** 내용에 딱 맞는 삽화를 만들 수 있습니다.

발표용 삽화 프롬프트의 핵심:

- **개념을 시각적 비유로 변환** (추상적 아이디어 → 구체적 장면)
- **깔끔하고 전문적인 스타일** (flat illustration, infographic style 등)
- **배경을 단순하게** (흰색 또는 단색 배경이 슬라이드에 삽입하기 좋음)

**시나리오:** "팀워크의 중요성"을 설명하는 슬라이드에 넣을 삽화

<details><summary>✅ 정답 예시</summary>

```
여러 사람이 함께 커다란 퍼즐 조각을 맞추고 있는 모습, 
각 사람은 서로 다른 색상의 퍼즐 조각을 들고 있다,
밝고 긍정적인 분위기, 흰색 배경, flat illustration 스타일,
깔끔한 선과 부드러운 색상, 비즈니스 프레젠테이션용
```

**응용 팁:**
- `white background` 또는 `transparent background`를 지정하면 슬라이드 삽입이 편합니다
- `flat illustration`, `vector style`, `infographic style`이 발표 자료에 잘 어울립니다
- 지나치게 사실적인 스타일보다 **일러스트 스타일**이 개념 전달에 효과적입니다

</details>

## 실습 7) 일관된 시리즈 만들기 `난이도 3`

> **📌 미션:** 같은 스타일과 분위기를 유지하면서 **3장의 연속 이미지**를 생성하세요.

실무에서는 하나의 이미지가 아닌 **일관된 스타일의 시리즈**가 필요한 경우가 많습니다 (예: 블로그 시리즈 썸네일, 발표 자료 삽화 세트, 제품 소개 이미지 등).

일관성을 유지하는 핵심 전략:

| 전략 | 설명 |
|------|------|
| **스타일 고정** | 동일한 스타일 키워드를 모든 프롬프트에 반복 사용 |
| **색상 팔레트 지정** | "파스텔 톤", "파란색과 흰색 위주" 등 색상 범위 명시 |
| **구도 통일** | 같은 앵글, 같은 여백 배치 유지 |
| **공통 요소** | 반복 등장하는 오브젝트나 캐릭터 명시 |

**시나리오:** "사계절 한국 풍경" 시리즈 — 봄, 여름, 가을 3장

<details><summary>✅ 정답 예시</summary>

**공통 스타일 템플릿:**
```
한국 시골 마을 풍경, 작은 기와집과 논밭이 보이는 언덕 위 시점,
[계절별 요소], 부드러운 수채화 스타일, 따뜻한 색감, 평화로운 분위기
```

**봄:**
```
한국 시골 마을 풍경, 작은 기와집과 논밭이 보이는 언덕 위 시점,
벚꽃이 만개한 봄, 연분홍 꽃잎이 날리고 있다, 
부드러운 수채화 스타일, 따뜻한 색감, 평화로운 분위기
```

**여름:**
```
한국 시골 마을 풍경, 작은 기와집과 논밭이 보이는 언덕 위 시점,
초록빛 논이 가득한 한여름, 뭉게구름이 떠 있는 파란 하늘,
부드러운 수채화 스타일, 따뜻한 색감, 평화로운 분위기
```

**가을:**
```
한국 시골 마을 풍경, 작은 기와집과 논밭이 보이는 언덕 위 시점,
단풍이 물든 가을, 황금빛 벼가 익은 논밭, 
부드러운 수채화 스타일, 따뜻한 색감, 평화로운 분위기
```

**핵심:** 프롬프트의 **앞부분(장소, 구도, 스타일)을 고정**하고, **계절별 요소만 변경**하면 일관된 시리즈가 완성됩니다.

</details>

## 마무리

### 오늘 배운 핵심 정리

| 기법 | 핵심 포인트 | 활용 상황 |
|------|------------|----------|
| **기본 프롬프트** | 주제를 명확하게 한 문장으로 | 빠른 아이디어 확인 |
| **4요소 묘사** | 주제 + 배경 + 분위기 + 구도 | 구체적인 장면 생성 |
| **스타일 키워드** | 프롬프트 끝에 화풍/스타일 추가 | 용도에 맞는 분위기 연출 |
| **수정 요청** | 추가/제거/변경을 한 번에 하나씩 | 결과물 점진적 개선 |
| **실무 썸네일** | 여백 확보 + 밝은 색상 + 비율 지정 | SNS 콘텐츠 제작 |
| **발표 삽화** | 개념의 시각적 비유 + 깔끔한 스타일 | 프레젠테이션 자료 |
| **시리즈 일관성** | 공통 템플릿 + 변수만 교체 | 연속 콘텐츠 제작 |

> 💡 **다음 단계:** 오늘 생성한 이미지 중 가장 마음에 드는 것을 골라 실제 SNS에 올리거나 발표 자료에 삽입해보세요. 실전에서 써봐야 실력이 늘어납니다!
