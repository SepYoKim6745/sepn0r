## 1. AI 발전 타임라인

인공지능은 1950년대부터 시작되어 긴 역사를 가지고 있습니다.

| 시기 | 주요 사건 |
|------|----------|
| 1950년대 | 앨런 튜링의 "튜링 테스트" 제안 |
| 1960~80년대 | 전문가 시스템, 첫 번째 AI 겨울 |
| 1990~2000년대 | 머신러닝 발전, IBM 딥블루 |
| 2010년대 | 딥러닝 혁명, AlphaGo |
| 2020년대 | GPT, 생성형 AI 시대 |

## 2. 인간의 두뇌와 딥러닝

딥러닝은 인간 두뇌의 신경망 구조를 모방한 학습 방법입니다.

- **뉴런(Neuron):** 정보를 처리하는 기본 단위
- **인공 신경망:** 뉴런을 여러 층으로 연결한 구조
- **딥러닝:** 깊은(Deep) 층을 가진 인공 신경망으로 학습하는 방법

```
입력층 → 은닉층1 → 은닉층2 → ... → 출력층
(데이터)   (특징 추출)   (패턴 학습)    (결과)
```

## 3. AI의 학습 방법

AI는 크게 3가지 방식으로 학습합니다.

### 지도학습 (Supervised Learning)

- 정답이 있는 데이터로 학습
- 예: 고양이/강아지 사진 분류, 스팸 메일 필터링

### 비지도학습 (Unsupervised Learning)

- 정답 없이 데이터의 패턴을 스스로 찾음
- 예: 고객 그룹 분류, 이상 탐지

### 강화학습 (Reinforcement Learning)

- 보상과 벌칙을 통해 최적의 행동을 학습
- 예: AlphaGo, 로봇 제어, 게임 AI

### 확인 문제

"정답 데이터 없이 비슷한 고객끼리 그룹을 나누는 것"은 어떤 학습 방법인가요?

<details><summary>정답 확인</summary>

정답: **비지도학습(Unsupervised Learning)** -- 정답 라벨 없이 데이터의 패턴과 유사성을 스스로 찾아 그룹화합니다.

</details>

## 4. AI의 대분류: 판단 모델 vs 생성 모델

### 판단 모델 (Discriminative Model)

- 입력 데이터를 **분류하거나 판단**하는 모델
- "이 사진은 고양이인가, 강아지인가?"
- 예: 스팸 필터, 질병 진단, 신용 평가

### 생성 모델 (Generative Model)

- 학습한 데이터를 바탕으로 **새로운 콘텐츠를 만들어내는** 모델
- "고양이 사진을 새로 만들어줘"
- 예: ChatGPT(텍스트), DALL-E(이미지), Suno(음악)

| 구분 | 판단 모델 | 생성 모델 |
|------|----------|----------|
| 목적 | 분류/예측 | 새로운 콘텐츠 생성 |
| 질문 | "이것은 A인가 B인가?" | "A와 비슷한 것을 만들어줘" |
| 예시 | 스팸 필터, 얼굴 인식 | ChatGPT, 이미지 생성 |

### 확인 문제

다음 중 **생성 모델**에 해당하는 것은?

- (a) 이메일이 스팸인지 아닌지 분류하기
- (b) 주어진 주제로 블로그 글 작성하기
- (c) 환자의 X-ray 사진에서 질병 판단하기
- (d) 주식 가격이 오를지 내릴지 예측하기

<details><summary>정답 확인</summary>

정답: **(b)** -- 새로운 텍스트 콘텐츠를 생성하는 것은 생성 모델의 역할입니다. 나머지는 모두 분류/예측을 수행하는 판단 모델입니다.

</details>

## 5. 생성형 AI의 종류

생성형 AI는 만들어내는 콘텐츠의 유형에 따라 나뉩니다.

| 유형 | 설명 | 대표 서비스 |
|------|------|------------|
| 텍스트 생성 | 글, 코드, 번역 등 | ChatGPT, Claude, Gemini |
| 이미지 생성 | 그림, 사진, 디자인 | DALL-E, Midjourney, Stable Diffusion |
| 음성/음악 생성 | 목소리, 음악 | Suno, ElevenLabs |
| 영상 생성 | 동영상 콘텐츠 | Sora, Runway |
| 코드 생성 | 프로그래밍 코드 | GitHub Copilot, Claude Code |

## 6. 언어 모델 계층 구조

생성형 AI의 핵심인 언어 모델은 다음과 같은 계층 구조를 가집니다.

```
AI (인공지능)
  └─ Machine Learning (머신러닝)
       └─ Deep Learning (딥러닝)
            └─ NLP (자연어 처리)
                 └─ LLM (대규모 언어 모델)
                      └─ GPT, Claude, Gemini ...
```

- **LLM(Large Language Model):** 대량의 텍스트 데이터를 학습한 거대한 언어 모델
- **GPT:** Generative Pre-trained Transformer의 약자

## 7. GPT로 이해하는 생성형 AI

### GPT의 동작 원리

GPT는 "다음에 올 단어를 예측"하는 방식으로 작동합니다.

```
입력: "오늘 날씨가 정말"
예측: "좋다" (가장 높은 확률의 다음 단어)
```

이 과정을 반복하여 문장, 문단, 글 전체를 생성합니다.

### GPT의 발전

| 버전 | 특징 |
|------|------|
| GPT-1 | 트랜스포머 기반 언어 모델의 시작 |
| GPT-2 | 텍스트 생성 품질 향상 |
| GPT-3 | 1750억 개 매개변수, Few-shot 학습 가능 |
| GPT-4 | 멀티모달(텍스트+이미지) 지원 |
| GPT-4o | 실시간 음성/영상 대화 지원 |

### 확인 문제

GPT가 텍스트를 생성하는 기본 원리는 무엇인가요?

<details><summary>정답 확인</summary>

정답: **다음에 올 단어(토큰)를 확률적으로 예측**하는 것입니다. 이전까지의 텍스트를 보고 가장 적절한 다음 단어를 선택하는 과정을 반복하여 전체 문장을 생성합니다.

</details>
