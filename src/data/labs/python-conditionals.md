## 1. 조건문(if)이란?

프로그램을 작성하다 보면 특정 조건에 따라 다른 코드를 실행해야 할 때가 있습니다. 예를 들어, 시험 점수가 60점 이상이면 "합격", 미만이면 "불합격"을 출력하는 경우입니다.

이처럼 조건에 따라 코드의 실행 흐름을 다르게 만드는 것이 **조건문**입니다.

조건문은 **비교 연산자**를 사용해 조건의 참(`True`)/거짓(`False`)을 판단합니다.

| 연산자 | 의미 | 예시 |
|--------|------|------|
| `==` | 같다 | `x == 5` |
| `!=` | 같지 않다 | `x != 5` |
| `>` | 크다 | `x > 5` |
| `<` | 작다 | `x < 5` |
| `>=` | 크거나 같다 | `x >= 5` |
| `<=` | 작거나 같다 | `x <= 5` |

## 2. if문의 기본 구조

`if`문은 조건식이 `True`일 때만 들여쓰기된 코드를 실행합니다.

```python
if 조건식:
    실행할 코드
```

주의할 점은 조건식 뒤에 반드시 콜론(`:`)을 붙이고, 실행할 코드는 **들여쓰기(4칸 공백)**를 해야 한다는 것입니다.

```python
num = 10

if num > 0:
    print("양수입니다.")
```

출력:

```
양수입니다.
```

조건이 거짓이면 들여쓰기된 코드는 실행되지 않고 넘어갑니다.

```python
num = -3

if num > 0:
    print("양수입니다.")

print("프로그램 끝")
```

출력:

```
프로그램 끝
```

## 3. if-else문

`else`는 `if`의 조건이 거짓일 때 실행할 코드를 지정합니다.

```python
if 조건식:
    실행할 코드 A
else:
    실행할 코드 B
```

조건이 참이면 코드 A가, 거짓이면 코드 B가 실행됩니다. 둘 중 하나는 반드시 실행됩니다.

```python
num = 7

if num % 2 == 0:
    print("짝수입니다.")
else:
    print("홀수입니다.")
```

출력:

```
홀수입니다.
```

`num % 2`는 `num`을 2로 나눈 나머지를 구합니다. 나머지가 0이면 짝수, 아니면 홀수입니다.

## 4. 다중 조건문(if-elif-else)

조건이 여러 개일 때는 `elif`(else if의 줄임말)를 사용합니다. 위에서부터 조건을 차례대로 검사하고, 처음으로 참인 조건의 코드만 실행합니다.

```python
if 조건식1:
    실행할 코드 A
elif 조건식2:
    실행할 코드 B
elif 조건식3:
    실행할 코드 C
else:
    실행할 코드 D
```

`else`는 위의 모든 조건에 해당하지 않을 때 실행됩니다.

```python
score = 85

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("F학점")
```

출력:

```
B학점
```

`score`가 85이므로 첫 번째 조건(`score >= 90`)은 거짓이고, 두 번째 조건(`score >= 80`)이 참이므로 "B학점"이 출력됩니다. 나머지 조건은 검사하지 않습니다.

## 5. 중첩 if문

`if`문 안에 또 다른 `if`문을 넣을 수 있습니다. 이를 **중첩 if문**이라고 합니다. 첫 번째 조건을 만족한 경우에만 두 번째 조건을 검사합니다.

```python
num = int(input("숫자를 입력하세요: "))

if num % 2 == 0:
    print("짝수입니다.")
    if num > 10:
        print("그리고 10보다 큽니다.")
    else:
        print("하지만 10보다 크지 않습니다.")
else:
    print("홀수입니다.")
```

입력이 `12`일 때 출력:

```
짝수입니다.
그리고 10보다 큽니다.
```

입력이 `4`일 때 출력:

```
짝수입니다.
하지만 10보다 크지 않습니다.
```

입력이 `7`일 때 출력:

```
홀수입니다.
```

중첩 if문을 사용할 때는 들여쓰기를 정확하게 맞추는 것이 중요합니다. 안쪽 if문은 바깥쪽 if문보다 한 단계 더 들여쓰기합니다.
