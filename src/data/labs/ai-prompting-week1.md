## 실습 1) R.C.I.F.C `난이도 1`

> **📌 미션:** 아래 프롬프트를 R.C.I.F.C로 개선하여 프롬프트를 작성하세요.

**프롬프트 예시:** `여행 일정 짜줘.`

| 요소 | 내용 | 예시 정답 |
|------|------|-----------|
| R (Role) | 누구처럼 답할지 | |
| C (Context) | 어떤 상황인지 | |
| I (Instruction) | 무엇을 할지 | |
| F (Format) | 어떤 모양으로 낼지 | |
| C (Constraint) | 무엇을 지킬지 | |

<details><summary>✅ 정답 예시</summary>

```
너는 여행 전문 플래너야. 친구 3명과 5월 3박 4일로 오사카 여행 가려고 해.
날짜별로 여행 일정을 짜줘. 하루하루 오전/오후/저녁으로 나눠서 표로 정리해주고, 
이동 거리가 너무 멀어지지 않게 동선 고려해줘.
```

| 요소 | 내용 | 정답 |
|------|------|------|
| R | 누구처럼 답할지 | 너는 여행 전문 플래너야 |
| C | 어떤 상황인지 | 친구 3명이랑 5월에 3박 4일로 오사카 여행 가려고 해 |
| I | 무엇을 할지 | 날짜별로 여행 일정을 짜줘 |
| F | 어떤 모양으로 낼지 | 하루하루 오전/오후/저녁으로 나눠서 표로 정리해줘 |
| C | 무엇을 지킬지 | 이동거리가 너무 멀어지지 않게 동선 고려해줘. |

</details>

<details><summary>✅ 정답 예시</summary>


| I | ✅ | 블로그 글 써줘 |

## 실습 8) Few-shot Prompting-5

> **📌 미션:** 같은 요청을 두 방식으로 보내고 차이를 직접 느껴보세요.

**주제:** 월요일 아침 기분 좋은 인사말 만들기

**Zero-shot (예시 없음):**

```
월요일 아침에 팀원들에게 보낼 활기찬 인사 메시지를 써줘.
```

**Few-shot (예시 있음):**

```
요일과 날씨에 맞는 팀원 인사 메시지를 써주세요.
2~3문장, 밝고 간결한 톤으로 작성합니다.

요일/날씨: 금요일 맑음
메시지: "드디어 금요일입니다! 오늘 하루도 힘내면 주말이 기다리고 있어요 😊 파이팅!"

요일/날씨: 수요일 비
메시지: "오늘은 비가 오네요. 따뜻한 커피 한 잔과 함께 차분하게 집중하는 수요일 만들어봐요 ☕"

요일/날씨: 월요일 맑음
메시지:
```

## 실습 9) Chain-of-Thought-1

> **📌 미션:** 아래 두 프롬프트를 순서대로 ChatGPT에게 입력하고 답변을 비교하세요.

**일반 프롬프트:**

```
다음 중 면접에서 좋은 인상을 주는 행동은?

(a) 모르는 질문에 그냥 "모릅니다"라고만 답한다
(b) 답변 전에 "잠깐 생각해봐도 될까요?"라고 양해를 구한다
(c) 면접관이 말하는 도중에 답변을 시작한다
(d) 자신의 단점을 말할 때 극복 노력도 함께 이야기한다
```

**CoT 프롬프트:**

```
다음 중 면접에서 좋은 인상을 주는 행동은?

(a) 모르는 질문에 그냥 "모릅니다"라고만 답한다
(b) 답변 전에 "잠깐 생각해봐도 될까요?"라고 양해를 구한다
(c) 면접관이 말하는 도중에 답변을 시작한다
(d) 자신의 단점을 말할 때 극복 노력도 함께 이야기한다

각 보기를 하나씩 검토하고, 왜 좋은지 나쁜지 이유를 설명한 뒤 최종 답을 알려줘.
```

## 실습 10) Chain-of-Thought-2

> **📌 미션:** 아래 두 프롬프트를 순서대로 ChatGPT에게 입력하고 답변을 비교하세요.

**일반 프롬프트:**

```
취업 준비할 때 뭘 먼저 해야 해?

(a) 자격증 취득
(b) 희망 직무와 회사 리서치
(c) 자기소개서 작성
(d) 포트폴리오 만들기
```

**CoT 프롬프트:**

```
취업 준비를 막 시작한 사람이라면 뭘 먼저 해야 할까?

(a) 자격증 취득
(b) 희망 직무와 회사 리서치
(c) 자기소개서 작성
(d) 포트폴리오 만들기

단계별로 생각해줘:
1단계: 각 항목을 하면 어떤 결과가 생기는지 설명해
2단계: 항목들 사이의 순서 관계를 파악해 (예: A를 해야 B를 할 수 있는지 등)
3단계: 처음 시작하는 사람에게 가장 적절한 순서를 추천해줘
```

## 실습 11) Chain-of-Thought-3

> **📌 미션:** 아래 상황을 기반으로 프롬프트 템플릿을 통해 프롬프트를 작성하시오.

**프롬프트 템플릿:**

```
[상황 설명]
나는 ___을 준비 중인 20대 남/여성이야.
현재 상황: ___

[질문]
___에 대해 분석해줘.

[CoT 요청]
단계별로 생각해줘:
1단계: ___
2단계: ___
3단계: 최종 결론을 내려줘
```

**예시 프롬프트:**

```
[상황 설명]
나는 첫 해외여행을 준비 중인 25살 남성이야.
현재 상황:
- 예산은 100만원
- 여행 기간은 5박 6일
- 혼자 여행 처음이라 치안이 좀 걱정됨
- 여름 휴가라 7월 말 출발 예정
- 후보지: 일본 오사카 vs 태국 방콕

[질문]
어느 여행지가 나한테 더 맞는지 분석해줘.

[CoT 요청]
단계별로 생각해줘:
1단계: 두 여행지를 예산, 치안, 7월 날씨 기준으로 각각 비교해줘
2단계: 혼자 첫 여행인 나한테 어떤 점이 유리하고 불리한지 분석해줘
3단계: 최종 결론을 내려줘.
```

## 실습 12) Persona / Role-play-1

> **📌 미션:** 아래 3개 프롬프트를 그대로 복사해서 GPT에 붙여넣고, 답변이 어떻게 다른지 확인하세요.

**아무것도 없이:**

```
카페 알바 면접 준비 어떻게 해야 해?
```

**역할만 짧게:**

```
당신은 면접 전문가입니다.
카페 알바 면접 준비 어떻게 해야 해?
```

**구체적인 페르소나:**

```
당신은 스타벅스에서 5년간 근무하고 현재 매장 매니저로 일하고 있습니다.
신입 지원자를 매주 면접하며, 첫인상과 솔직한 답변을 가장 중요하게 봅니다.

저는 내일 카페 알바 면접이 있는 취준생입니다.
면접관이 자주 묻는 질문 3가지와 각각 어떻게 답하면 좋은지 알려주세요.
```

## 실습 13) Persona / Role-play-2

> **📌 미션:** 아래 프롬프트에서 빈칸을 채우고 GPT에 입력하세요.

**프롬프트 템플릿:**

```
당신은 [1]를 운영하는 크리에이터입니다.
주로 [2] 시청자들이 좋아하는 콘텐츠를 만들며,
[3]을 가장 중요하게 생각합니다.

제가 만들려는 영상 주제는 [4]입니다.
이 주제로 유튜브 썸네일 문구 3개와 인스타그램 게시글 캡션을 작성해주세요.
```

**빈칸 예시:**

| 빈칸 | 예시 |
|------|------|

## 실습 17) Meta Prompting-3

> **📌 미션:** 아래 소재 목록에서 하나를 골라, 메타 프롬프트를 직접 작성하고 AI가 만들어준 프롬프트를 R.C.I.F.C로 검수 후 최종 프롬프트를 완성하세요.

| 소재 | 예시 상황 |
|------|-----------|
| 이력서 자기소개 | 1분 자기소개 스크립트를 AI로 만들고 싶다. |
| 회의 안건 정리 | 팀 회의 내용을 요약/정리하는 프롬프트가 필요하다 |
| SNS 콘텐츠 기획 | 인스타그램용 직무 관련 게시물 초안을 빠르게 뽑고 싶다. |
| 자유 주제 | 여행, 관광지 등 자유 주제 |

**메타프롬프트 작성 템플릿:**

```
나는 [역할/상황]이야.
내가 원하는 결과물은 [구체적 결과물]이야.
사용 도구는 ChatGPT이고, [제약조건: 분량/형식/톤]이 있어.
이 상황에 맞는 최적의 프롬프트를 R.C.I.F.C 구조로 만들어줘.
```

**예시 — 메타 프롬프트:**

```
나는 유통 물류 회사 영업직 취업을 준비 중인 취업준비생이야.
면접 첫 질문인 "1분 자기소개"를 ChatGPT로 준비하려고 해.
비전공자이고 공백기 6개월이 있어. 자신감 있는 톤으로, 150자 이내로 말할 수 있는 스크립트가 필요해.
이 상황에 맞는 최적의 ChatGPT 프롬프트를 R.C.I.F.C 구조로 만들어줘.
```

**예시 — 완성 버전:**

```
당신은 면접 코칭 전문가입니다. (R)
아래 정보를 가진 취업준비생의 1분 자기소개 스크립트를 작성해주세요. (C+I)
- 지원 직무: 영업 (유통 물류)
- 비전공자 / 공백기 6개월 존재
형식: 말하기용 구어체, 문장 5개 이내, 150자 내외 (F)
제약: 공백기를 긍정적으로 재해석하는 방향, 과장 없이 자신감 있는 톤 (C)
```
