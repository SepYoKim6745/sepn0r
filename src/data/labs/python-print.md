## 1. print() 함수란?

`print()` 함수는 화면에 값을 출력하는 Python의 기본 내장 함수입니다. 프로그램의 결과를 확인하거나, 디버깅할 때 가장 많이 사용합니다.

```python
print("Hello, Python!")
```

출력:

```
Hello, Python!
```

## 2. 기본 출력

`print()` 함수는 문자열, 숫자, 소수점 등 다양한 자료형을 출력할 수 있습니다.

```python
# 문자열 출력
print("안녕하세요")

# 정수 출력
print(123)

# 실수 출력
print(3.14)

# 계산 결과 출력
print(10 + 20)
```

출력:

```
안녕하세요
123
3.14
30
```

## 3. 여러 값 출력

쉼표(`,`)로 여러 값을 나열하면 한 줄에 출력됩니다. 기본적으로 값 사이에 공백이 들어갑니다.

```python
name = "민수"
age = 17

print("이름:", name)
print("나이:", age)
```

출력:

```
이름: 민수
나이: 17
```

### sep 매개변수

`sep` 매개변수를 사용하면 값 사이의 구분자를 변경할 수 있습니다.

```python
# 기본 구분자는 공백
print("사과", "바나나", "포도")

# 구분자를 쉼표로 변경
print("사과", "바나나", "포도", sep=", ")

# 구분자를 하이픈으로 변경
print("2026", "04", "26", sep="-")

# 구분자 없이 붙여서 출력
print("H", "e", "l", "l", "o", sep="")
```

출력:

```
사과 바나나 포도
사과, 바나나, 포도
2026-04-26
Hello
```

## 4. end 매개변수

`print()` 함수는 기본적으로 출력 후 줄바꿈을 합니다. `end` 매개변수를 사용하면 줄바꿈 대신 다른 문자를 넣을 수 있습니다.

```python
# 기본 동작: 줄바꿈
print("Hello")
print("World")
```

출력:

```
Hello
World
```

```python
# end 매개변수로 줄바꿈 대신 공백 사용
print("Hello", end=" ")
print("World")
```

출력:

```
Hello World
```

```python
# end 매개변수로 화살표 연결
print("시작", end=" -> ")
print("중간", end=" -> ")
print("끝")
```

출력:

```
시작 -> 중간 -> 끝
```

## 5. f-string 포맷팅

f-string은 문자열 앞에 `f`를 붙이고 중괄호 `{}` 안에 변수를 넣어 값을 삽입하는 방법입니다. Python 3.6 이상에서 사용할 수 있습니다.

```python
name = "민수"
age = 17
score = 95.5

print(f"안녕하세요, {name}님!")
print(f"나이: {age}세")
print(f"평균 점수: {score}점")
```

출력:

```
안녕하세요, 민수님!
나이: 17세
평균 점수: 95.5점
```

f-string 안에서 계산도 가능합니다.

```python
price = 1500
quantity = 3

print(f"총 금액: {price * quantity}원")
```

출력:

```
총 금액: 4500원
```

## 6. 여러 줄 출력

여러 줄에 걸친 텍스트를 출력하려면 삼중 따옴표(`"""` 또는 `'''`)를 사용합니다.

```python
print("""========
 공지사항
========
1. 내일 시험입니다.
2. 교재를 지참하세요.""")
```

출력:

```
========
 공지사항
========
1. 내일 시험입니다.
2. 교재를 지참하세요.
```
