## 1. 들여쓰기란?

들여쓰기(indentation)란 코드의 시작 부분을 일정한 간격으로 띄워서 작성하는 것입니다.

대부분의 프로그래밍 언어에서는 중괄호 `{}`로 코드 블록을 구분하지만, Python은 들여쓰기로 코드 블록을 구분합니다. 따라서 Python에서 들여쓰기는 단순한 스타일이 아니라 문법의 일부입니다.

```python
# C, Java 등 다른 언어의 코드 블록
# if (조건) {
#     실행할 코드
# }

# Python의 코드 블록
if True:
    print("들여쓰기로 블록을 구분합니다")
```

## 2. 들여쓰기의 규칙

### 규칙 1: 공백 4칸을 사용한다

Python 공식 스타일 가이드(PEP 8)에서는 공백 4칸을 권장합니다.

```python
if True:
    print("공백 4칸으로 들여쓰기")  # 올바른 방법
```

### 규칙 2: 스페이스와 탭을 혼용하지 않는다

같은 파일 안에서 스페이스와 탭을 섞어 쓰면 `TabError`가 발생합니다. 하나만 선택해서 사용해야 합니다.

```python
# 잘못된 예 (스페이스와 탭 혼용)
if True:
    print("스페이스 4칸")    # 스페이스
	print("탭 1칸")          # 탭 -> TabError 발생!
```

### 규칙 3: 같은 블록은 같은 깊이로 들여쓴다

하나의 블록 안에서는 모든 줄이 동일한 간격으로 들여쓰기 되어야 합니다.

```python
# 잘못된 예 (들여쓰기 불일치)
if True:
    print("4칸")
      print("6칸")  # IndentationError 발생!
```

## 3. 올바른 들여쓰기 예제

### 예제 1: if 조건문

```python
score = 85

if score >= 90:
    print("A학점입니다")
    print("우수한 성적입니다")
```

`if` 아래의 두 줄이 모두 공백 4칸으로 들여쓰기 되어 있으므로, 둘 다 조건이 참일 때 실행됩니다.

### 예제 2: if-else 조건문

```python
age = 17

if age >= 20:
    print("성인입니다")
    print("투표할 수 있습니다")
else:
    print("미성년자입니다")
    print("투표할 수 없습니다")
```

출력:

```
미성년자입니다
투표할 수 없습니다
```

### 예제 3: 중첩 들여쓰기

코드 블록 안에 또 다른 블록이 있으면, 들여쓰기가 한 단계 더 깊어집니다.

```python
number = 15

if number > 0:
    print("양수입니다")          # 4칸
    if number > 10:
        print("10보다 큽니다")   # 8칸 (4칸 + 4칸)
```

출력:

```
양수입니다
10보다 큽니다
```

## 4. 자주 하는 실수

### 실수 1: 들여쓰기를 하지 않은 경우

```python
if True:
print("들여쓰기를 안 했어요!")  # IndentationError 발생!
```

올바른 코드:

```python
if True:
    print("들여쓰기를 했어요!")  # 정상 작동
```

### 실수 2: 불필요한 들여쓰기

```python
name = "민수"
    print(name)  # IndentationError 발생! (블록 밖인데 들여쓰기)
```

올바른 코드:

```python
name = "민수"
print(name)  # 정상 작동
```

### 실수 3: 콜론(:) 빠뜨리기

들여쓰기와 함께 `if`, `for`, `while`, `def` 등의 끝에는 반드시 콜론(`:`)이 필요합니다.

```python
if True     # SyntaxError 발생! (콜론이 없음)
    print("콜론을 빠뜨렸어요")
```

올바른 코드:

```python
if True:    # 콜론 필수
    print("콜론을 넣었어요")
```
