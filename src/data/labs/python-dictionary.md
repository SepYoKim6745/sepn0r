## 1. 딕셔너리란?

딕셔너리(dictionary)는 **키(key)**와 **값(value)**을 쌍으로 저장하는 자료형입니다. 사전에서 단어를 찾으면 뜻이 나오는 것처럼, 키를 사용해 값을 찾는 구조입니다.

```python
student = {
    "이름": "철수",
    "나이": 20,
    "학교": "서울고등학교"
}

print(student)
```

출력:

```
{'이름': '철수', '나이': 20, '학교': '서울고등학교'}
```

딕셔너리의 특징은 다음과 같습니다.

- 중괄호 `{}`로 감싸고, `키: 값` 형태로 작성합니다.
- 키는 중복될 수 없습니다.
- 키는 문자열, 숫자 등 변경 불가능한(immutable) 타입만 가능합니다.
- 값은 어떤 타입이든 가능합니다.

## 2. 기본 사용법

### 값 접근

대괄호 `[]` 안에 키를 넣어 값을 가져옵니다.

```python
student = {
    "이름": "철수",
    "나이": 20,
    "학교": "서울고등학교"
}

print(student["이름"])
print(student["나이"])
```

출력:

```
철수
20
```

`get()` 메서드를 사용하면 키가 없을 때 오류 대신 기본값을 반환합니다.

```python
print(student.get("이름"))         # 철수
print(student.get("전화번호"))     # None
print(student.get("전화번호", "정보 없음"))  # 정보 없음
```

### 값 추가 및 수정

존재하지 않는 키에 값을 대입하면 새로운 항목이 추가되고, 존재하는 키에 값을 대입하면 기존 값이 수정됩니다.

```python
student = {"이름": "철수", "나이": 20}

# 새 항목 추가
student["학년"] = 3
print(student)

# 기존 값 수정
student["나이"] = 21
print(student)
```

출력:

```
{'이름': '철수', '나이': 20, '학년': 3}
{'이름': '철수', '나이': 21, '학년': 3}
```

### 값 삭제

`del` 키워드로 특정 키-값 쌍을 삭제합니다.

```python
student = {"이름": "철수", "나이": 20, "학교": "서울고등학교"}

del student["학교"]
print(student)
```

출력:

```
{'이름': '철수', '나이': 20}
```

### 키 존재 여부 확인

`in` 키워드로 특정 키가 딕셔너리에 있는지 확인할 수 있습니다.

```python
student = {"이름": "철수", "나이": 20}

print("이름" in student)
print("전화번호" in student)
```

출력:

```
True
False
```

## 3. 반복문 사용

딕셔너리는 반복문과 함께 사용할 수 있습니다.

### keys() - 키만 반복

```python
student = {"이름": "철수", "나이": 20, "학교": "서울고등학교"}

for key in student.keys():
    print(key)
```

출력:

```
이름
나이
학교
```

### values() - 값만 반복

```python
for value in student.values():
    print(value)
```

출력:

```
철수
20
서울고등학교
```

### items() - 키와 값 함께 반복

```python
for key, value in student.items():
    print(f"{key}: {value}")
```

출력:

```
이름: 철수
나이: 20
학교: 서울고등학교
```

## 4. 실습 예제

### 예제 1: 전화번호부 만들기

```python
phone_book = {}

# 연락처 추가
phone_book["민수"] = "010-1234-5678"
phone_book["지영"] = "010-9876-5432"
phone_book["철수"] = "010-1111-2222"

# 전체 연락처 출력
print("=== 전화번호부 ===")
for name, number in phone_book.items():
    print(f"{name}: {number}")
```

출력:

```
=== 전화번호부 ===
민수: 010-1234-5678
지영: 010-9876-5432
철수: 010-1111-2222
```

### 예제 2: 과목 점수 평균 구하기

```python
scores = {
    "국어": 90,
    "영어": 85,
    "수학": 95,
    "과학": 88
}

total = 0
for subject, score in scores.items():
    print(f"{subject}: {score}점")
    total += score

average = total / len(scores)
print(f"\n총점: {total}점")
print(f"평균: {average}점")
```

출력:

```
국어: 90점
영어: 85점
수학: 95점
과학: 88점

총점: 358점
평균: 89.5점
```

### 예제 3: 키 존재 여부 확인 활용

```python
menu = {
    "아메리카노": 4500,
    "라떼": 5000,
    "녹차": 4000
}

order = "라떼"

if order in menu:
    print(f"{order}: {menu[order]}원")
else:
    print(f"{order}는 메뉴에 없습니다.")
```

출력:

```
라떼: 5000원
```
