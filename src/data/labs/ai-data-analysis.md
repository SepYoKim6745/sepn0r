## 실습 1) 함수 요청 4요소 익히기 `난이도 1`

> **📌 미션:** AI에게 함수를 시킬 때 **목적·데이터 구조·원하는 결과·플랫폼** 4요소를 빠짐없이 채워서 프롬프트 1개를 작성하세요.

**함수를 외우는 시대는 끝 — AI에게 시키면 된다. 단, AI가 무엇을 만들 수 있는지를 알아야한다.**

**자주 쓰는 함수 6개의 정체:**

| 함수 | 하는 일 | 실무 예시 |
|------|---------|---------|
| SUM | 숫자들을 모두 더한다 | 월별 매출 합계, 총 수량 |
| AVERAGE | 숫자들의 평균을 낸다 | 평균 단가, 평균 근무 시간 |
| IF | 조건에 따라 다른 값을 보여준다 | 100만원 이상이면 '우수', 아니면 '일반' |
| VLOOKUP | 다른 표에서 값을 찾아온다 | 제품 코드로 단가 자동 매칭 |
| COUNTIF | 조건에 맞는 셀의 개수를 센다 | 특정 사원의 매출 건수 |
| CONCATENATE | 여러 셀의 글자를 합친다 | 성+이름, 주소 통합 |

**AI에게 함수를 시키는 4가지 정보:**

| # | 요소 | 질문 | 예시 |
|---|------|------|------|
| 1 | 목적 | 무엇을 하고 싶은가? | '매출 합계를 내고 싶다' |
| 2 | 데이터 구조 | 어떤 셀·범위·컬럼이 있는가? | 'B열에 매출 / 30행까지' |
| 3 | 원하는 결과 | 어떤 형태로 받고 싶은가? | '한 셀에 합계 표시' |
| 4 | 플랫폼 | Excel? Google Sheets? | 'Excel용 함수로' |

**Before — 막연한 요청 (이렇게 하면 안 됨)**

<details><summary>📋 나쁜 예시 보기</summary>

```
SUM 함수 알려줘
```

**문제:**
- 내 데이터에 바로 적용 불가
- 어디에 어떻게 적용할지 다시 물어야 함

</details>

<details><summary>✅ 정답 예시 — 4요소를 모두 채운 프롬프트</summary>

```
너는 엑셀 함수 전문가야.

[데이터]
- A열: 날짜
- B열: 영업사원명
- C열: 매출액
- 데이터 범위: 2~31행 (30행)

[원하는 작업]
F2 셀에 전체 매출 합계를 표시하고 싶어.

[형식]
- 함수 한 줄만 알려줘
- 설명은 한 줄 이내로 간단히

[플랫폼]
Excel 2021에서 사용할 거야.
```

**결과:**
- 바로 복붙해서 쓸 수 있는 정확한 함수 도출
- 같은 함수(SUM)이지만, 맥락이 있을 때만 "내 업무에 바로 쓸 수 있는 답"이 나온다

</details>

## 실습 2) SUM·COUNTIF·AVERAGE 함수 받기 `난이도 1`

> **📌 미션:** 실습 데이터 "1분기_매출현황.xlsx"를 열고, 아래 3가지 함수를 Gemini에게 요청하세요.

**실습 데이터:** "1분기_매출현황.xlsx" (30행) — 컬럼: 날짜 / 영업사원명 / 제품 / 수량 / 단가 / 매출액

| 미션 | 함수 | 내용 |
|------|------|------|
| 미션 1 | SUM | 전체 매출 합계 — F열(매출액)의 합계를 한 셀에 표시 |
| 미션 2 | COUNTIF | 영업사원별 매출 건수 — 특정 영업사원(예: '김민준')의 매출 건수 세기 |
| 미션 3 | AVERAGE | 평균 단가 — E열(단가)의 평균을 구하는 함수 |

<details><summary>✅ 프롬프트 예시 — 미션 1 (SUM)</summary>

```
너는 엑셀 함수 전문가야.

[데이터]
- F열: 매출액
- 데이터 범위: 2~31행 (30행)

[원하는 작업]
H2 셀에 전체 매출 합계를 표시하고 싶어.

[형식]
함수 한 줄만 알려줘

[플랫폼]
Excel 2021
```

</details>

> 💡 **추가미션:** 먼저 끝낸 사람은 **제품별 단가 합계(미션 4)**, **가장 매출 많은 사람 찾기(미션 5)** 에 도전.

## 실습 3) AI 함수 검수 3단계 `난이도 2`

> **📌 미션:** AI가 준 함수가 항상 옳다는 보장은 없습니다. 실행 전에 반드시 3가지를 확인하세요.

**"좋은 요리사는 손님에게 내기 전에 반드시 한 입 맛본다."** Gemini가 만들어 준 함수도 똑같다. 실행 전에 1건은 직접 계산해본다.

**검수 3단계:**

| 단계 | 확인 항목 | 방법 | 예시 |
|------|---------|------|------|
| ① 수동 1건 확인 | 데이터 첫 행 1개를 손이나 계산기로 직접 계산 | 함수 결과와 비교 | B2-B11의 합계가 1,250만이라면 → 직접 더해본 값과 같은가? |
| ② 빈 셀·에러 확인 | 결과에 #N/A, #DIV/0!, #VALUE! 같은 에러 확인 | 에러가 있으면 함수가 잘못된 신호 | VLOOKUP 결과 일부가 #N/A → 매칭 안 되는 값이 있다는 뜻 |
| ③ 경계값 테스트 | 조건의 경계(딱 100만원, 0, 빈 셀)에서 의도대로 작동하는지 | 경계 데이터를 직접 넣어보기 | '100만원 이상이면 우수' → 정확히 100만원일때 '우수' 나오는가? |

> ⚠️ **3가지 중 하나라도 이상하면, 함수를 그대로 쓰지 말고 Gemini에게 다시 묻는다.**

**가장 자주 마주치는 AI 함수 오류 3가지:**

| 오류 유형 | 예시 |
|---------|------|
| 범위 오류 | B2:B31이어야 하는데 B2:B30으로 나오기도 |
| 함수 이름 차이 | Excel은 CONCATENATE, Sheets는 CONCAT 권장 |
| 조건문 누락 | '1팀 평균'을 요청했는데 전체 평균을 주기도 |

> ⚠️ **절대 참조 영역도 필수적으로 확인 필요!!**

## 실습 4) IF·VLOOKUP 함수 + 검수하기 `난이도 2`

> **📌 미션:** IF 함수와 VLOOKUP 함수를 AI에게 요청하고, 검수 체크리스트로 결과를 확인한 뒤, 틀린 부분은 Gemini에 다시 요청하세요.

**4단계 워크플로:**

1. IF 함수: 매출액 100만원 이상이면 '우수', 아니면 '일반' 표시
2. VLOOKUP 함수: 제품코드 표에서 단가를 자동으로 찾아오기 (의도적 오류 포함)
3. 검수 체크리스트로 결과 확인 → 틀린 부분 Gemini에 다시 요청
4. 위 작업을 Google Sheets에서 재현 (한 줄 후속 요청 활용)

<details><summary>📋 실습 프롬프트 4단계</summary>

```
[01] G열 매출액이 100만 이상이면 "우수", 미만이면 "일반"으로 H열에 표시

[02] 매출현황 C열 제품코드로 제품정보 시트에서 단가(F열)를 찾는 VLOOKUP 함수

[03] 이 함수에서 N/A 에러가 나오는데 원인과 해결책 알려줘

[04] 방금 준 함수를 Google Sheets용으로 바꿔줘
```

</details>

> ⚠️ **생성형 AI와 엑셀을 다룰 때 주의할 사항 존재!! — 보안 문제 중요**

**Gemini에게 Excel 입력하는 방법 (보안 수준별):**

| 수준 | 방법 | 설명 |
|------|------|------|
| 낮음 | 파일 업로드 | Gemini에 직접 파일 첨부 |
| 보통 | 텍스트 복붙 | 데이터를 텍스트로 복사해서 붙여넣기 |
| 높음 | 구조만 설명 | 컬럼명·범위·행 수만 텍스트로 전달 |

## 실습 5) 플랫폼 변환 프롬프트 `난이도 1`

> **📌 미션:** AI에게 받은 Excel 함수를 Google Sheets용으로 변환하세요. 새 프롬프트가 아니라 **한 줄 후속 요청**이면 충분합니다.

**Excel과 Google Sheets 90%는 같다. 그런데 10%가 발목을 잡는다.**

| 구분 | Excel | Google Sheets |
|------|-------|---------------|
| 함수 이름 차이 | CONCATENATE | CONCAT (or &) |
| 구분자 차이 | 일부 지역 ';' 사용 | 거의 항상 ',' |
| 전용 함수 존재 | — | GOOGLEFINANCE, IMPORTRANGE 등 |

<details><summary>✅ 정답 예시 — 변환 시드 프롬프트</summary>

```
방금 준 함수는 Excel용이야.
이걸 Google Sheets에서도 똑같이 작동하는 함수로 바꿔줘.

[변환 시 신경 써줘야 할 것]
- 함수 이름이 다른 경우 알려주기
- Sheets 전용 더 좋은 함수가 있다면 추천
- 기능이 동일한지 확인
```

</details>

**같은 뜻, 다른 표현:**

| 기능 | Excel | Google Sheets |
|------|-------|---------------|
| 문자 합치기 | CONCATENATE(A1, B1) | A1 & B1 |
| 에러 처리 | =IFERROR(VLOOKUP(...)) | =IFERROR(VLOOKUP(...)) |
| 오늘 날짜 | =TODAY() | =TODAY() |
| 데이터 집계 | =PIVOT 기능 (UI) | =QUERY(...) |

> 💡 **Excel ↔ Sheets 양방향 모두 가능. 새 프롬프트가 아니라 후속 요청 한 줄.**

## 실습 6) VBA 환경 세팅 `난이도 1`

> **📌 미션:** Excel 개발 도구 탭을 활성화하고, VBA 편집기를 열어 코드 입력 창을 준비하세요.

**VBA가 만드는 6가지 변신:**

| 내 업무에서 이런 일이 있다면 | VBA 매크로 |
|------------------------|----------|
| 매주 같은 보고서 표에 똑같이 색·테두리 입힌다 | 셀 서식 매크로 |
| 매월 매출 데이터로 같은 차트를 손으로 만든다 | 차트 자동 생성 |
| 담당자별 시트로 매번 손으로 나눠 보낸다 | 시트 자동 분리 |
| 보고서에 사진 여러 장 일일이 정렬한다 | 이미지 정렬 |
| 받은 데이터마다 헤더·필터를 손으로 만든다 | 헤더·필터 매크로 |
| 다른 사람 자료에 빈 행·중복이 섞여 있다 | 데이터 자동 정리 |

> 💡 **핵심: 손이 같은 동작을 반복하고 있다면, VBA가 그 일을 대신할 수 있다.**

<details><summary>📋 STEP 1~3 따라하기</summary>

```
STEP 1. 개발 도구 탭 활성화
   파일 → 옵션 → 리본 사용자 지정 → "개발 도구" 체크
   왜? VBA 편집기를 열려면 필요

STEP 2. VBA 편집기 열기
   Alt + F11 → VBA 편집기 창 열림

STEP 3. 모듈 삽입
   삽입 → 모듈 → 코드 입력 창 준비
```

</details>

## 실습 7) 셀 서식 자동 꾸미기 — VBA 매크로 A `난이도 2`

> **📌 미션:** '매출현황' 시트에 셀 테두리·색상 등을 자동 적용하는 VBA 매크로를 Gemini에게 받아 실행하세요.

**AI에게 VBA를 시키는 5가지 정보 (함수 4요소 + 오류처리):**

| # | 요소 | 질문 | 예시 |
|---|------|------|------|
| 1 | 입력 | 어떤 데이터에 작용? | B2~G31 범위 |
| 2 | 작업 | 무엇을 하라? | 100만↑ 초록 칠하기 |
| 3 | 출력 | 결과를 어디에? | 같은 시트 / 새 시트 |
| 4 | 오류처리 | 데이터 없으면? | 메시지박스 띄우기 |
| 5 | 플랫폼 | 어느 Excel? | Excel 2021 (한글) |

> 💡 **4번 '오류처리'만 추가하면 함수 프롬프트가 매크로 프롬프트가 된다.**

<details><summary>✅ 정답 예시 — VBA 5요소 시드 프롬프트</summary>

```
너는 VBA 매크로 작성 전문가야.

[입력 데이터]
- 시트명: 매출현황
- 헤더: 1행 (A~G열)
- 데이터 범위: 2~31행 (G열 = 매출액)

[작업]
G열 매출액이 100만 이상이면 초록 배경,
50만 미만이면 빨강 배경을 칠하고,
헤더에 진한 색·테두리를 적용해줘.

[출력]
같은 시트에 적용. 새 시트 만들지 마.

[오류처리]
데이터가 없으면 "데이터 없음" 메시지박스.

[플랫폼]
Excel 2021 한글판. Sub Format_SalesStatus() 형태로 작성.
```

</details>

## 실습 8) 시트 자동 분리 — VBA 매크로 C `난이도 2`

> **📌 미션:** 매출현황을 영업사원별 6개 시트로 자동 분할하는 매크로를 받아 실행하세요.

<details><summary>✅ 정답 예시 — 시트 분리 5요소 프롬프트</summary>

```
너는 VBA 매크로 작성 전문가야.

[입력 데이터]
- 원본 시트: 매출현황
- 헤더: 1행 (A~G열)
- 데이터: 2~31행
- 영업사원명은 B열

[작업]

## 실습 15) 할루시네이션 검증 `난이도 2`

```

## 실습 19) 반복 개선 — 후속 요청 5패턴 `난이도 2`

## 실습 21) HTML 저장·공유 `난이도 1`

> **📌 미션:** 완성된 대시보드를 **HTML 파일로 다운로드**하고 공유 방법을 선택하세요.

**내가 만든 대시보드가 HTML 파일 1개로 변한다.**

**4단계 공유 워크플로:**

| 단계 | 할 일 | 팁 |
|------|------|-----|
| 1. Canvas에서 다운로드 | 우측 상단 다운로드 버튼 → "HTML 파일" 선택 | 확장자 .html 확인 |
| 2. 파일명 변경 | 기본명을 알아보기 쉽게 (예: "박스오피스_2024Q4.html") | 한글 가능, 공백은 _ 로 |
| 3. 공유 방법 선택 | 메일 첨부 / 카톡 / USB / 클라우드 | 용량은 보통 100KB 이하 |
| 4. 수신자가 더블클릭 | 브라우저에서 자동으로 열림 → 필터·차트 다 작동 | 별도 설치 필요 없음 |

**Canvas 모드의 한계:**

| 할 수 있는 것 | 못 하는 것 |
|------------|---------|
| 고정된 데이터로 차트·표 만들기 | 실시간 데이터 자동 업데이트 |
| 필터·정렬·검색 등 인터랙션 | DB 연결 (SQL·MySQL 등) |
| 여러 차트 한 화면에 배치 | 사용자 로그인·권한 관리 |
| 색상·레이아웃·스타일 커스텀 | 원본 데이터가 바뀌면 자동 반영 |
| HTML 파일로 다운로드·공유 | 동시 편집 (Google Sheets처럼) |
| 오프라인에서도 작동 (열기만 하면) | 데이터 양 매우 많을 때 (수천 행+) |

> 💡 **"이번 분기 보고용 한 컷" 같은 정적 대시보드에 최적. 실시간 대시보드는 별도 도구.**

## 마무리 — 5단계 통합 워크플로 정리

| 단계 | 활용 모듈 | 핵심 도구 | 결과물 |
|------|---------|---------|--------|
| 01 함수 | M1 | 4요소 프롬프트 + 검수 3단계 | =SUM(...) 같은 정확한 함수 |
| 02 자동화 | M2 | VBA 5요소 + 오류 대화 | .xlsm 매크로 6개 |
| 03 정제·분석 | M3 | 5가지 병 + 분석 의뢰서 + 검증 3원칙 | 정제된 데이터 + 인사이트 |
| 04 시각화 | M4 | Canvas 4요소 + 반복 개선 | HTML 대시보드 1개 |
| 05 통합 | M5 | 공공데이터 → 대시보드 → 공유 | HTML 파일 1개 + 발표 1줄 |

**핵심 정리 3가지:**

1. **함수를 외우지 말고 시켜라** — 4요소만 채우면 AI가 정확한 함수를 준다. 단, 검수 3단계는 필수.
2. **분석의 적은 할루시네이션** — 매끄러운 문장이 정확한 문장은 아니다. 검증 3원칙으로 잡는다.
3. **대시보드는 한 번에 안 된다** — 첫 결과는 항상 미완성. 후속 요청으로 "한 번에 하나씩" 다듬는다.
